# Skill: report-style

How to write clip2trace provenance reports.

## Voice
- Concise, evidence-backed, careful.
- Every claim references a score, timestamp, link, or observable clue.

## Required language
- Use: "candidate", "likely Telegram source candidate", "evidence suggests",
  "earlier known Telegram appearance", "best candidate found".
- Avoid: "broadcast" / "compilation" as the product category (those are use
  cases). The product is **provenance and source tracing**.

## Forbidden in automated output
- "confirmed original", "the original post", "we found the original".
- Any claim of certainty that the candidate is the first appearance.

A human reviewer may add a manually-verified note *outside* the automated
confidence score; that note must be explicitly marked as human-verified.

## Structure
Summary → mode (demo/live) → segments → ranked candidates (link, channel, time,
confidence+label, evidence, caveats) → global caveats → next steps.
